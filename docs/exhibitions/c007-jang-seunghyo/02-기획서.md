# c007 장승효 《꿈꾸는 트리》 — 2. 전시 기획서

기획서(슬라이드 14장): https://claude.ai/artifact/5Tb4XsN7bSJY7K99QSwKmt

- 메시지: 흩어진 조각을 모으면, 꿈이 피어난다 (장자의 호접몽)
- 주제: 크리스마스 트리 = 한 해의 조각을 모아 붙인 콜라주
- PART 1 트리를 피우는 밤(7장면): 첫 조각(누르기) → 줍기(기울이기) → 자라기(길게 누르기·들어 올리기) → 나의 장식(카메라 오너먼트) → 눈(흔들기 스노우볼) → 별(나침반 북쪽·후 불기) → 꿈(엎어 두면 나비 꿈, 들면 점등)
- PART 2 작품과 작가: 작품 사진·영상, 작가 노트, 나의 트리 카드, 작품 소장 상담
- 제안 일정: 11/20 확정 · 11/27 시안 · 12/1 오픈(12월 호 표지)
- 결정 필요: 유료/무료, 마감일, 콜라주플러스 작품 사용 여부(김용민 작가 동의)

## 전광판 콜라보 '모두의 트리' (2026-11-16 추가, 소유자 요청)
참고: 롯데월드 '메이플스토리 인 롯데월드'(2026 봄) — QR로 캐릭터를 만들어 전광판에 띄우는 이벤트.
- 흐름: 전광판 아래 QR(또는 앱 '전광판으로 보내기') → 작가 조각으로 오너먼트 꾸미기 + 항해명 → 전광판으로 보내기(대기열) → 거대한 트리에 걸리고 10초간 이름 → 인증샷·나의 트리 카드
- 매시 정각 점등쇼, 12/24 카운트다운, 웹에서 같은 화면 생중계
- 기술: 전광판 = `screen.html` 전체화면 한 장, Supabase Realtime 으로 실시간 전달
- 안전: 1분마다 바뀌는 현장 QR·코드, 항해명 금칙어·글자 수, 운영자 숨기기, 사진 오너먼트는 폰에서만(전광판엔 작가 조각만), 기기당 3분 1회
- 협의 필요: 전광판 장소·해상도·운영 시간, 현장 PC·인터넷, Supabase 설정 마무리
