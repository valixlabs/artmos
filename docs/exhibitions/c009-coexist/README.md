# c009 자연선택 — 새로운 공존의 시작 (신예진)

- 2026-11-21 소유자가 포스터·로고('자연선택')를 줌 → 제목을 **자연선택**으로, '새로운 공존의 시작'은 부제와 마지막 문구로 남김. 파일 `assets/posters/c009-poster.webp`(3:4로 좌우를 조금 자름)·`-poster-s.webp`(540px)·`-logo.webp`(흰 글자, 투명 배경).

- 2026-11-21 공개(소유자 결정: 작가 계약 전 바로 공개). **작가와 협의 중** — 화면에도 "작가의 작업 세계에서 영감을 받아 ARTMOS가 만든 기획 전시(작가와 협의 중)"로 표시. 작가가 원하지 않으면 `data/remote.json`의 `closed`에 `c009`를 넣어 바로 닫을 것.
- 주제: 작가 인터뷰(공아트컴퍼니, 2025-03) 속 "자연이 기계를 받아들여 강해지는 것은 새로운 공존의 시작" 부분.
- 파일: `coexist.html`, `js/coexist.js`, `css/coexist.css`, 소리 `assets/coexist/snd/*.mp3`.
- 모양은 모두 코드로 새로 만듦(작품 사진·인스타그램 사진 안 씀): 고목(가지 재귀 생성), 사슬에 매달려 줄기에 박힌 엔진(도르래·톱니·밸브·빛나는 틈), 바닥에 말린 전선, 이끼, 안개.
- 체험: 나무 문지르기(나무 깨어남) · 엔진 누르기(켜기/끄기). 기계만 돌면 안개가 탁해지고 바람 소리가 줄어듦, 나무만 깨면 기계는 멈춰 있음, 둘이 함께면 엔진 빛이 가지로 흐르고 이끼가 자라며(한 번 자라면 남음) 새소리·배경음이 밝아짐. 공존 82%를 넘으면 "새로운 공존의 시작" 문구. 휴대폰은 기울이면 시점이 조금 움직임(`sensors.js`, 앱 안이면 센서 중계). 끌기 = 화면 돌리기, 두 손가락 = 확대·축소.
- 소리(입체: 엔진 소리는 엔진 자리에서 남, HRTF): 배경음(어두운 신전 같은 패드) · 숲 바람 · 새소리 · 엔진 공회전 · 톱니 · 고목 삐걱 · 나무 두드림 · 쇠 두드림 · 시동 · 꺼짐 · 공존 완성.
  - [earshot](https://github.com/Leonxlnx/earshot)(MIT, 결과물은 상업 이용 자유·표기 불필요)으로 만듦. 만든 설정은 이 폴더의 `sounds-spec*.json`(`earshot make --spec … -o … --format wav`). 엔진은 녹음된 엔진이 아니라 믹서기·세탁기·우주선 소리를 낮춰 만든 것.
  - 반복 소리(배경음·바람·새·엔진·톱니)는 이어 붙임 자국 없게 끝을 앞에 겹쳐 만들고, 파일 끝에 0.6초를 덧붙여 `loopStart 0.1 / loopEnd 0.1+길이`로 돎(mp3 앞 빈칸 영향 없음). 길이는 `js/coexist.js`의 `LOOPS`.
  - 소리를 사람이 들어 보고 고른 것은 아님 — 크기·느낌은 실제로 들으며 `mix()`의 숫자로 맞출 것.
- 아직 한국어만. `#debug`면 `window.__co`(speed·life·harm, setMachine·setLife).
