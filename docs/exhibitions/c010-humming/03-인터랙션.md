# 3. 인터랙션과 순서 — 《Humming Letter》 (2026-11-25 프로토타입·공개)

- 소유자(2026-11-25): **작품 14점 모두 사용, 제목은 그대로 'Humming Letter', 순서는 스토리에 맞게.**
- 스토리 흐름(작가 노트 순서): 지침 → 여행·정원 → 천국 → 바람 → 손가락 → 리듬 → 아버지의 꽃 → 보통의 포착 → 허밍 편지 → 꽃밭 위의 허밍.

| # | 장 | 작품 | 체험 (휴대폰 / PC) |
|---|---|---|---|
| 입장 | Humming Letter | 포스터(붉은 꽃밭) | 흰 선이 허밍처럼 출렁. '들어가기'(동작·마이크) / '마이크 없이' |
| 1 | 블루, 지친 날 | #01 | 어두운 파랑 막의 금을 문질러 열기 |

| 3 | 천국 그 자체 | 물길 → 호수 | 꾹 누르면 향기, 기울이면 빛 / 마우스로 빛 |
| 4 | 바람의 춤 | 붉은 꽃 → 초록 들 | 기울기·흔들기·후~·쓸기 / 쓸기·마이크 |
| 5 | 손가락으로 | 해바라기 | 평평하게 내려놓고 40초 안에 문질러 드러내기 / 마우스 |
| 6 | 나만의 리듬 | 주황 결 → 분홍 꽃 | 박자 두드리기·흔들기, 고르면 그림이 춤 / 클릭·스페이스 |
| 7 | 꽃은 항상 그 자리에 | 파란 물결 → 화분 | 흔들어도 꽃은 그대로 / 한 줄 적으면 꽃 한 송이 |

| 10 | 꽃밭 위에 허밍 | 청록 물결 + 13점 | 모든 입력이 꽃, 다 차면 만개 |
| 끝 | 작품과 소장 | 14점 | 작품 정보·크레딧·소장 상담 |
