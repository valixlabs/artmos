## 확인한 것 (클라우드 크롬, 390×844 터치)
- 모든 장을 내려가며 문지르기·누르기: 스크립트 오류 0, 가로 넘침 0.
- 실기기에서 아직 못 본 것: 아이폰 마이크(특히 앱 안 iframe), 평평하게 놓기 감지, 나침반 걷기.

## 작가 확인 필요 (00-권리.md와 같음)
- 아버지 이야기 인용(7장), 그림을 몇 px 흔드는 바람·물결 효과, 판매 조건·가격, 작가 영문 표기(지금 Kwon Jian).

## 3D 모델링 (2026-11-25 소유자: "그림 위에 하는 것보다 그림을 모델링해서 잘 구성")
- 사진 한 장 → 지도 5장(`tools/humming-model/model.py`): 색(그대로)·물감 결(노멀)·물감 높낮이(변위)·꽃 층·흰 선 층.
- 무대(`js/humming-3d.js`): 검은 벽에 걸린 실제 캔버스처럼 — 옆면 두께, 손가락으로 쌓은 물감의 높낮이에 빛이 걸림, 벽에 조명 웅덩이와 그림자. 기울이면 작품이 돌고 빛이 옮겨 가 결이 반짝임.
- 층을 나눠 움직임: 꽃 층만 바람에 흔들림(4장 바람의 춤, 3장 천국), 아래 물결만 출렁(7장, 6장 박자, 10장), 흰 선(허밍 편지)이 그림에서 떠오름(9장 — 허밍할수록, 다 쓰면 전부).
- 모네 3폭은 병풍처럼 살짝 접어 세움. 피날레 둘레 13점은 작은 캔버스로 궤도를 돎.
- 작품 사진의 색은 바꾸지 않음. 층 나누기·높낮이는 화면 연출용 어림값(작가 확인 필요 목록에 추가).
