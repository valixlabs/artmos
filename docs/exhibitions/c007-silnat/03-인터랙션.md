# 3. 인터랙션 — 실낱 같은 희망 (c007)

**원칙(소유자 결정)**: 센서를 쓰지 않습니다. 조작은 **스크롤 하나**이고, 스크롤한 만큼 바늘이 나아가며 붉은 실이 그어집니다. 그래서 권한 요청이 없고, 휴대폰과 PC가 같은 경험입니다.
- 실은 처음부터 끝까지 **한 줄**입니다(끊기지 않음). 되돌려 스크롤하면 실이 다시 감깁니다.
- 감정과 이어지는 장치는 단 하나, **속도**입니다. 사람에게 닿으면 실이 스크롤보다 천천히 그어집니다(약 0.4배). 관람객이 저절로 그 자리에 오래 머물게 됩니다.
- 화면에 색은 붉은 실 하나뿐입니다. 나머지는 종이색과 검은 실입니다.

## 공통
- **모션 줄이기**: 실이 스크롤에 따라 그려지는 건 그대로 두고, 감기·지그재그·떠오르기 효과는 빼고 바로 보이게 합니다.
- **권한 없음**: `sensors.js`는 불러오지 않습니다. 진동도 없습니다.
- **글**: 카드마다 3~5문장, 맨 아래 작은 글씨로 '가상의 인물 · 전시 문안'을 붙입니다. 외국어 화면에서는 장면마다 배경 한 줄을 넣습니다(예: 한국에서는 노인이 폐지를 주워 생계를 잇는 일이 흔합니다).
- **소리**: 음악은 없습니다. 스크롤 속도에 따라 종이를 스치는 잡음 합성(Web Audio, 아주 작게)을 넣고, 매듭 지을 때 짧은 당김 소리를 냅니다. iPhone 무음 스위치와 앱 전환은 기존 방식대로 대응합니다.
- **끝까지 보기**: 누르기는 8번 매듭 하나뿐이고 선택입니다. 아무것도 누르지 않아도 끝까지 볼 수 있습니다.

## 만드는 방식
- 이미 있는 블록에는 '스크롤로 이어지는 실 한 줄'이 없어서 **단독 페이지**로 만듭니다: `silnat.html` + `js/silnat.js` + `css/silnat.css`. 빛쌀과 같은 방식입니다.
- 실은 페이지 전체 높이의 SVG `path` 하나로 그리고, `stroke-dashoffset`을 스크롤 진행도에 맞춥니다. 사람 구간에서는 진행도를 0.4배로 눌러 줍니다. 바늘은 실 끝을 따라가는 작은 그림이고, 지나간 자리에는 바늘구멍 점을 남깁니다.
- 장면 그림(골목·편의점·버스·공장·문)은 검은 실 느낌의 SVG 선으로 우리가 새로 그립니다. **작가의 인물은 다시 그리지 않고 원작 이미지만 씁니다**(움직여도 되는지 동의가 오면 다시 검토).
- 원작 이미지를 받기 전까지는 '작품 이미지 자리' 회색 틀로 둡니다.
