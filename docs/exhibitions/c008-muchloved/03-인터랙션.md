# 3. 인터랙션 — MUCH LOVED (c008)

**원칙(소유자 결정, 2026-11-18)**: 센서를 모두 활용해 다양하게 체험합니다. 다만 **모든 장면은 센서 없이도 끝까지 볼 수 있어야 합니다**(버튼·끌기·누르기 대체).
- 조작은 늘 **쥐기·만지기·안기·곁에 두기**처럼 아끼는 몸짓입니다. 던지기·세게 흔들기·찢기는 받지 않습니다.
- 작품 사진에는 효과를 주지 않습니다. 닳고 걷히는 것은 우리 층(먼지 천·어둠·빛)뿐입니다.
- 화면은 검정·흰색·회색만 씁니다. 색은 작품 사진에만 있습니다.

## 공통
- **진동**: 아이폰 웹(사파리)은 `navigator.vibrate`를 지원하지 않습니다. 웹 아이폰에서는 진동 대신 화면 가장자리가 박동에 맞춰 아주 살짝 밝아집니다. 앱 껍데기에서 진동을 주려면 Haptics 플러그인과 `artmos:haptic` 메시지가 필요합니다 → **소유자 확인 필요**(껍데기 앱을 다시 내야 함).
- **모션 줄이기**: 천 걷힘·서랍·쿠션 움직임을 줄이고 바로 결과를 보여 줍니다. 진동은 그대로 둡니다.
- **소리**: 음악은 없습니다. 문지를 때 천 스치는 소리, 서랍 나무 소리, 후~ 먼지 소리를 아주 작게 합성합니다(Web Audio). 소리 끔 설정(`xpace-sound=off`)을 따릅니다.
- **캐릭터 작품**: 작가 확인 결과 상업 캐릭터인 작품은 `noZoom` 목록에 넣어 핀치와 쿠션·서랍 움직임을 끄고 사진만 보여 줍니다.
- **앱 안 iframe**: 기울기는 앱이 넘겨주는 방식(`artmos:sensor`)으로 이미 됩니다. 마이크·카메라가 iframe 안에서 되는지는 미확인 → 프로토타입을 실제 아이폰으로 확인하고, 안 되면 그 두 장면은 앱에서 버튼 대체로 시작합니다.
- **진행 저장**: 마지막으로 본 장면을 `valix-muchloved-step`에 저장해 '보던 전시'에 이어 보기를 표시합니다.

## 만드는 방식
- 단독 페이지: `muchloved.html` + `js/muchloved.js` + `css/muchloved.css`. 머리에 '앱처럼 보이게' 스타일과 두 번 탭 확대 막기를 넣습니다.
- 장면은 세로 스크롤 한 장씩 꽉 찬 화면(스냅). 각 장면에 들어오면 그 장면의 센서만 켜고, 나가면 끕니다(카메라·마이크는 즉시 끔).
- 먼지 천은 장면마다 `<canvas>` 하나(회색 천 결 노이즈)를 작품 사진 위에 겹치고, `destination-out`으로 지웁니다. 지운 비율은 64×64로 줄인 칸을 세어 계산합니다.
- 서랍·소파·은박 바닥은 우리가 그린 단순한 흑백 선과 면이고, 인형은 도록 사진(배경을 잘라 내지 않고 사각 그대로)을 씁니다. 사진을 잘라 내도 되는지는 작가 확인 후 다시 봅니다.
- 원본 사진을 받기 전까지는 도록 PDF에서 뽑은 이미지로 만들고, 받으면 바꿉니다.
