# 4. 대중성 점검 (2026-11-18, 기획서·인터랙션·입체 시험판 기준)

처음 보는 사람이 휴대폰으로 끝까지 볼 수 있는지를 장면마다 짚었습니다. 시제품 전이라 기획 기준입니다.

## 점검표
| 점검 | 결과 |
|---|---|
| 첫 화면 10초 안에 할 일을 앎 | ○ "화면을 꾹 눌러 보세요" 한 줄, 누르면 바로 진동·글 |
| 장면마다 할 일이 하나로 보임 | △ 액자 벽에 몸 돌리기·문지르기·후~·핀치 네 가지가 한꺼번에 있음 → **개선 1** |
| 전체 길이 | △ 어림 10~12분(장면 8개 × 1~1.5분). 앞선 전시(실낱 약 6분)보다 김 → **개선 2** |
| 권한 요청 | △ 동작·마이크·카메라 세 번. 앱 안에서는 동작은 앱이 받고, 마이크·카메라는 iframe에서 되는지 미확인 → **개선 3** |
| 어디서나 할 수 있음 | △ '가슴에 안기'·'엎어 두기'는 지하철·사무실에서 하기 어색함 → **개선 4** |
| 작품이 먼저 보임 | △ 먼지 천이 작품을 완전히 덮으면 처음엔 작품이 안 보임 → **개선 5** |
| 멈춘 것처럼 보이는 순간 | ✕ 엎어 둔 동안 화면이 검고 소리가 없음 → 다시 들었을 때 '고장'으로 오해할 수 있음 → **개선 6** |
| 이야기 먼저, 정보는 뒤 | ○ 장면 안에는 이름표(이름·재료)만, 작가 노트·약력은 맺음에 |
| 끝에 남는 한 장면 | ○ 나의 인형 이름표. 간직하기(이미지 저장)로 가져감 |
| 공감의 문 | ○ "당신이 가장 오래 쥐고 있던 것은?"으로 시작해 "당신의 인형 이름은?"으로 끝남 |
| 외국어 | △ 작품 이름이 영어라 그대로 두고, 애착 인형 문화 설명은 필요 없음. 작가 노트 번역은 작가 확인 후 |
| 입체 보기 | △ 많이 돌리면 옆면이 얇은 판처럼 보임 → ±20°로 줄임(반영함). 소파 PEANUT은 몸 일부만 입체 |
| PC | ○ 모든 센서에 끌기·버튼 대체 |
| 모션 줄이기 | ○ 숨 쉬듯 흔들림·천 걷힘 끔, 결과 바로 |
| 작가 의도와 어긋나지 않음 | △ 작가 검토 필요(입체로 만든 방식, 먼지 천, 나의 인형 이름표가 작품 이름표를 닮은 것) |
| 시범 관람 3명 | ✕ 아직 — 시제품이 나오면 소유자·작가·처음 보는 1명 |

## 개선안 (소유자 결정 필요)
1. **장면마다 꼭 할 일은 하나, 나머지는 덤**
   - 액자 벽: 꼭 할 일 = **문지르기**(첫 액자 하나만 다 걷으면 다음으로 갈 수 있음). 나머지 다섯 액자는 몸 돌리기·넘기기로 지나가도 되고, 후~·핀치는 '이렇게도 할 수 있어요' 작은 칩으로.
   - 소파: 꼭 할 일 = 기울이기. 토닥이기는 덤.
   - 은빛 바닥: 꼭 할 일 = 돌리기(또는 넘기기). 잠들기는 마지막 한 번만.
2. **길이 줄이기 (목표 7~8분)**
   - 액자 벽 6점은 한 액자당 머무는 시간을 짧게(다 걷지 않아도 3초 뒤 '다음' 화살표).
   - 끌어안기(장면 4)는 소파 장면 끝에 붙여 따로 장면을 만들지 않음.
   - 각 장면 위쪽에 남은 장면 점(●○○○) 표시.
3. **권한은 '쓸 때'만, 거절해도 손해 없음**
   - 마이크·카메라는 버튼을 누른 사람에게만 물음. 처음부터 묻지 않음.
   - 앱 안에서 iframe 마이크·카메라가 안 되면 그 두 동작은 앱에서 숨기고 버튼 대체만 보여 줌(시제품에서 실기기 확인).
4. **조용한 대안을 같은 크기로**
   - '가슴에 안기'와 나란히 **'두 손으로 감싸기'**(화면을 두 손가락 이상으로 덮고 있기)를 같은 크기 버튼으로. 카메라 권한도 필요 없음. 권장: 감싸기를 기본, 가슴에 안기는 덤.
   - 엎어 두기 대신 **'화면 위에 손 얹기'**(손바닥으로 화면 가리기 = 넓은 터치)도 잠들기로 받음.
5. **먼지 천은 반투명으로 시작**
   - 처음부터 인형 윤곽과 색이 흐리게 비치게(천 불투명도 70%). 무엇을 걷는지 알고 문지름.
6. **잠든 동안에도 무언가 남겨 두기**
   - 엎어 두기 직전 "들어 올리면 깨어나요" 한 줄을 3초 보여 줌.
   - 엎어 둔 동안 화면은 아주 어두운 회색에 시간만 천천히 올라감(00:01, 00:02…). 다시 들면 그 숫자가 "○분 ○초 동안 곁에 있었어요"로 바뀜.

## 남은 확인
- 작가: PEANUT 이름 두 곳, FLOOPY 다리 옆 작은 회색 물체가 작품인지, 입체 방식·먼지 천 연출 괜찮은지, 인형마다 짧은 이야기.
- 기기: 아이폰 실기기 앱 안 마이크·카메라, 아이폰 진동 대체(화면 박동)가 느껴지는지.
